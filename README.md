# Gudrā klase

Gudrā klase ir vienkāršs projekts skolēniem un skolotājiem: vieta, kur apkopot mācību materiālus, uzdevumus un noderīgas saites.

## Kas ir iekšā

- `index.html` — projekta sākumlapa
- `README.md` — šis apraksts

## Kā atvērt

Lejupielādējiet repozitoriju un atveriet failu `index.html` savā pārlūkprogrammā.

## Nākotnes idejas

- Uzdevumu un testu sadaļa
- Mācību materiālu saraksts pa priekšmetiem
- Klases kalendārs un paziņojumi
